# Document Management Dashboard

## Features

- Single File Upload
- Multiple File Upload
- Upload Progress Tracking
- Upload Status Tracking
- File Type Display
- Upload Date Display
- Total Files Count
- Total Storage Used
- Download Files
- Delete Files

## Tech Stack

Frontend:
- React
- Axios

Backend:
- Node.js
- Express
- Multer

## Run Frontend

cd frontend
npm install
npm run dev

## Run Backend

cd backend
npm install
node server.js
